# i2x

> i2x GmbH (i2x.ai) is a German real-time AI platform for contact centers, headquartered at Berliner Platz 12, 41061 Mönchengladbach, and registered at the Amtsgericht Berlin-Charlottenburg. It combines live agent assistance during calls (contextual recommendations rendered in under 0.4 seconds, automatic purchase-signal detection, faster onboarding of new agents), full-coverage post-call analysis (automatic transcription plus quality, compliance and sales-opportunity scoring across 100% of conversations rather than samples), and voicebots for automated inbound/outbound telephony and virtual customer training scenarios. The company positions itself on DSGVO/GDPR compliance, EU-only hosting in German data centers, a prepared works-council documentation package, and EU AI Act alignment — an explicitly DACH-market alternative to US-cloud-dependent conversation-intelligence tools.
>
> i2x DOES NOT PUBLISH AN API. There is no developer portal, no API reference, no OpenAPI or AsyncAPI specification, no GraphQL SDL, no MCP server, no A2A agent card, no SDK on any package registry, no public GitHub organization, no webhook catalog, no status page, no changelog and no pricing. The product is sold through a demo-request form and a sales conversation. ## What an agent can and cannot do here

- There is **no callable i2x API surface available to an agent**. Nothing in this file is an endpoint you can invoke.
- A private, undocumented API host does exist: `https://api.eu.i2x.ai` (Go service, honest hard 404s, EU region). It is the backend of the customer web application at `https://app.i2x.ai` and is authentication-gated — `POST /organizations/v1/login` is the session entry point (a GET returns HTTP 405). It is not a developer product: no contract, no reference, no key issuance, no terms of use for third-party integrators. Do not treat it as an integration target.
- A development/playground host resolves at `https://api-dev.eu.i2x.ai` (CNAME `i2x-api.playground.dev.i2x.ai`). It answers 404 on every probed path and is likewise undocumented.
- To integrate with i2x, the only published route is contacting the company: hello@i2x.ai or +49 2161 9479 350.
